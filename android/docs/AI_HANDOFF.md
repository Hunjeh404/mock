## 알려진 범위

콘텐츠는 내장 JSON이라 변경 때 재빌드가 필요합니다. 인원은 현재 선택 가능한 값에 대응하는 도형만 제공합니다. 시맨틱 AI 검색·실시간 인물 정렬 판정·자동 구도 평가·편집실은 구현하지 않았습니다. 앱의 갤러리는 이 앱이 촬영한 사진을 확인·공유하는 용도입니다.

서명 키는 Git에 포함하지 않습니다. 사용자의 원래 FilmRoom 개발 서명 키 사본은 전달용 소스 ZIP의 signing 폴더에 보존되며, 기존 설치 ID가 다르므로 FilmRoom을 덮어쓰지 않습니다. ZIP은 사용자용 개발 자료이고 공개 저장소에 키를 추가하지 마세요.

- 자동/프로는 탭 즉시 전환. RAW+JPG와 3:2 표시는 제거하고 투명도/색상으로 교체했습니다.
- 프레임 상단 ‘자동 · 보도 클린’ 라벨은 삭제했습니다.
- 당시에는 세로 창 안에 가로 프레임을 고정했습니다. 이 해석은 1.1.1에서 폐기했습니다. 아래 최신 방향 정책을 따르세요.
- 명부/암부 빨간 빗금과 위험 문구는 화면에만 표시합니다. 실제 센서 RAW 클리핑을 확정한 것으로 설명하지 마세요.
- 사진 확인 화면 우측 상단 삭제, 목록의 선택/전체 선택/장누르기/일괄 삭제를 추가했습니다.
- 추가 검사: 0 투명도 및 7색 저장, 전체 회전 가로 출력, DNG 센서 보존, 실제 GLSL 명부/암부 마스크, 미디어 어댑터의 RAW/JPG 쌍 삭제·실패/저장 중 보호.
- Android 실기기의 키보드 팝업, 삭제 권한/실제 MediaStore 반영, 빗금 위치·경고 반응, 회전한 미리보기와 저장 사진의 구도는 아직 별도 확인해야 합니다.

## 1.1.1 인계 — 실제 가로 촬영

- 실제 휴대폰 자세 90/270에서만 촬영하며 0/180은 안내/차단합니다. 세로 창에 가로 프레임을 강제로 넣지 않습니다. 메뉴는 세로, 가이드와 실제 촬영은 가로입니다.
- 미리보기/터치 측광은 displayDegrees, 저장 방향은 CaptureOrientation.engineRotation을 사용합니다. 이 두 회전을 다시 하나로 통일하면 프리뷰 구도가 틀어집니다.
- 타이머 중 세로 전환 시 취소 + 촬영 직전 자세 재검사 + 타이머 세대 번호로 지난 콜백을 무시합니다.
- 투명도 숫자를 좌우 드래그하면 즉시 0~100으로 조절합니다. 오른쪽 증가/왼쪽 감소, 별도 팝업 탭 진입은 제거했습니다. 색상 팝업은 앱 카드/스와치/선택 체크로 통일했습니다.
- 갤러리 선택/취소는 내용 기반 너비(최소 88dp), 테마 강조/선택 상태, 말줄임 제거로 변경했습니다.
- APK는 사용자에게 별도로 전달하며 공개 Git에는 소스/문서만 올립니다. 서명키나 바이너리 공개 업로드를 재시도하지 마세요.
