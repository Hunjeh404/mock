# 다음 AI 작업자에게

## 현재 상태

- 원본: 사용자 제공 FilmRoom Android 0.1.26 APK + 저장되어 있던 동일 버전 소스
- 결과: 보도사진 카메라 1.1.0, 별도 설치 ID `com.hoonjay.presscamera`
- 자동/프로, 단일 보도 클린 프리셋, RAW+JPG, 3:2, 네이티브 가이드 선택 메뉴를 연결했습니다.
- 편집 화면/기존 특수 모드/프리셋 관리 진입점은 없습니다.
- 분류/추천/안내/도형은 assets에 있으며 앞으로의 수정은 CONTENT_GUIDE의 경로를 우선합니다.

## 먼저 확인

1. AGENTS.md와 제품 매니페스트
2. 수정하려는 항목이 문구/데이터인지, 엔진 동작인지 구분
3. catalog의 안정 ID를 보존하고 새 참조가 유효한지 검증
4. captureRatio와 DNG default crop를 다르게 설정하지 않기
5. 바뀐 버전과 서명 키를 유지하여 기존 설치 앱의 업데이트가 가능하게 하기

## 통과한 검사

- Java/Android 리소스 컴파일, DEX 패키징, APK 정렬과 v3 서명
- 제품 정책, 20개 분류/20개 사진, 인원/소품/가로세로 도형의 참조 검증
- 네이티브 GuideCatalog의 복합 분류, 한국어/영문 키워드, 중복 제거, 선택 복원
- 항상 가로 3:2, 4방향 회전과 DNG 크롭 대응, 디테일 상한
- DNG 기본 크롭 변경 전후 센서 샘플·보정 정보 보존, little/big endian 및 SubIFD
- 원본 촬영 초점 대기 정책 및 핵심 RAW·색상·좌표 회귀 검사
- 실제 GLSL 컴파일과 시험 텍스처 GPU/CPU 비교, 새 프리셋 포함

이는 실기기 촬영 검증을 대신하지 않습니다.

## 실기기에서 확인할 항목

- 자동 첫 화면에서 ISO·셔터·EV·초점이 숨겨지는지
- 프로 진입 시 네 다이얼이 보이고 실제 사진 설정에 반영되는지
- 프로의 수동값을 바꾼 뒤 자동으로 복귀하면 AF/AE가 다시 작동하는지
- 각 RAW 지원 렌즈에서 연속 촬영, 초점 대기, 플래시가 정상인지
- 세로·가로 회전 시 JPG 방향과 가이드 방향이 맞는지
- 팝업 검색 시 키보드가 적용 버튼을 가리지 않는지
- 적용 전 닫기/뒤로가 원래 선택을 복원하는지
- JPG에 가이드가 합성되지 않는지
- 동일 이름의 DNG/JPG 한 쌍과 사진첩 저장 위치
- RAW 뷰어가 기본 크롭을 적용하는지(센서 원본 크기는 그대로 유지)
- JPG 화질·노출·초점·색상, 특히 실내 고ISO/역광/피부/글자
- JPG 개발 중 앱을 종료한 뒤 RAW 보존과 미완료 복구

## 알려진 범위

콘텐츠는 내장 JSON이라 변경 때 재빌드가 필요합니다. 인원은 현재 선택 가능한 값에 대응하는 도형만 제공합니다. 시맨틱 AI 검색·실시간 인물 정렬 판정·자동 구도 평가·편집실은 구현하지 않았습니다. 앱의 갤러리는 이 앱이 촬영한 사진을 확인·공유하는 용도입니다.

서명 키는 Git에 포함하지 않습니다. 사용자의 원래 FilmRoom 개발 서명 키 사본은 전달용 소스 ZIP의 signing 폴더에 보존되며, 기존 설치 ID가 다르므로 FilmRoom을 덮어쓰지 않습니다. ZIP은 사용자용 개발 자료이고 공개 저장소에 키를 추가하지 마세요.

## 1.1.0 인계

- 자동/프로는 탭 즉시 전환. RAW+JPG와 3:2 표시는 제거하고 투명도/색상으로 교체했습니다.
- 프레임 상단 ‘자동 · 보도 클린’ 라벨은 삭제했습니다.
- 메뉴는 세로, 촬영 프레임/가이드/저장 JPG는 항상 가로입니다. Preview의 회전과 촬영의 회전을 일치시키고 터치 측광 좌표도 같은 회전을 사용합니다.
- 명부/암부 빨간 빗금과 위험 문구는 화면에만 표시합니다. 실제 센서 RAW 클리핑을 확정한 것으로 설명하지 마세요.
- 사진 확인 화면 우측 상단 삭제, 목록의 선택/전체 선택/장누르기/일괄 삭제를 추가했습니다.
- 추가 검사: 0 투명도 및 7색 저장, 전체 회전 가로 출력, DNG 센서 보존, 실제 GLSL 명부/암부 마스크, 미디어 어댑터의 RAW/JPG 쌍 삭제·실패/저장 중 보호.
- Android 실기기의 키보드 팝업, 삭제 권한/실제 MediaStore 반영, 빗금 위치·경고 반응, 회전한 미리보기와 저장 사진의 구도는 아직 별도 확인해야 합니다.
