# 변경 이력

## 1.1.1

- 실제 휴대폰 가로 자세에서만 촬영하도록 수정. 세로 안내/셔터 차단, 타이머 취소/촬영 직전 재확인.
- 세로 메뉴와 프리뷰 좌표를 유지하면서 가이드만 휴대폰 자세에 맞춰 가로로 회전.
- 상단 투명도를 좌우 드래그로 0~100 즉시 조절.
- 가이드 색상 팝업을 어두운 카드, 7색 스와치, 테마색 선택 체크로 통일.
- 사진 선택/취소 버튼의 글자·아이콘이 잘리지 않도록 내용 기반 너비와 테마 선택 상태 적용.

## 1.1.0

- 명부·암부 빨간 빗금과 검은 배경/테마색 위험 안내
- 자동/프로 탭 즉시 전환
- 메뉴 세로 유지, 촬영 프레임·가이드·JPG 가로 고정 및 RAW 크롭 대응
- RAW+JPG/3:2 표기를 가이드 투명도(0~100)·7색 선택으로 교체
- 프레임 상단 자동/보도 클린 라벨 삭제
- 확인 화면 우측 상단 삭제, 목록 다중 선택·전체 선택·일괄 삭제
- 저장 중 보호, RAW/JPG 쌍 삭제, 실패 수 분리 보고
